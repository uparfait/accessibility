On-screen keyboard

Shows a keyboard on the screen, so you can type with a mouse, a touch screen or another pointing device.

How to use

  1. Click into a text box
  2. Press the keys on the screen keyboard
  3. Drag the top bar to move the keyboard

Special keys

  • Shift: one capital letter. Press twice for all capitals
  • 123: numbers and symbols
  • Arrows: move inside the text

Use it from your own code

The setting is called vkeyboard. Use true to turn it on and false to turn it off.

Accessibles.set('vkeyboard', true);    // on
Accessibles.set('vkeyboard', false);   // off
Accessibles.get('vkeyboard');          // is it on?
