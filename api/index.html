JavaScript API

Once the widget has started, window.Accessibles lets your own page open the panel, change settings and listen to what visitors do.

Wait until it is ready

The widget starts after the page has loaded. If your code runs early, wait for the accessibles:ready event first:

addEventListener('accessibles:ready', function () {
  Accessibles.set('fontSize', 1.3);
});

Code inside a click handler doesn't need this, because nobody can click before the page is ready.

What you can call

CallWhat it does
Accessibles.open()Opens the panel.
Accessibles.close()Closes the panel.
Accessibles.toggle()Opens the panel if it is closed, closes it if it is open.
Accessibles.set('fontSize', 1.3)Changes one setting. The list of settings is below.
Accessibles.get('contrast')Gives the value of one setting.
Accessibles.get()Gives every setting at once.
Accessibles.profile('dyslexia')Turns a profile on, or off if it is on.
Accessibles.reset()Puts every setting back to how it was at the start.
Accessibles.readPage()Turns on read aloud and reads the main content of the page.
Accessibles.audit()Checks the page and gives back a score from 0 to 100, with every check and what it found.

Events

addEventListener('accessibles:ready', function (event) {
  console.log('Accessibles', event.detail.version, 'is ready');
});

addEventListener('accessibles:change', function (event) {
  // event.detail.key, event.detail.value and every setting in event.detail.state
  if (event.detail.key === 'contrast') document.body.dataset.theme = event.detail.value || 'default';
});

Your own content for some features

A few features can use what you already know about your site. Put these in window.AccessiblesConfig, before the widget's script:

<script>
  window.AccessiblesConfig = {
    // Checked first when a visitor looks up a word
    glossary: { ISBN: 'International Standard Book Number' },

    // Real descriptions for pictures, for example from your own service
    altText: async function (image) {
      const response = await fetch('/api/describe?src=' + encodeURIComponent(image.src));
      return response.text();
    },

    // Your own summary of the page: a text, or a list of points
    summarize: async function (text) {
      const response = await fetch('/api/summary', { method: 'POST', body: text });
      return response.json();
    },

    // Sign language videos for parts of the page
    signVideos: { '#intro': '/media/intro-asl.mp4' }
  };
</script>

You can also give any element its own sign language video with data-acc-sign="video.mp4".
