Options

Options change how the widget looks and where it sends things. None of them is required.

Three ways to set an option

Use whichever fits your site. Option names don't care about capitals or dashes, so site-name, siteName and sitename all work.

On the div, with data attributes

<div class="accessibles-widget" data-color="#7B3F00" data-position="bottom-left"></div>

In the script address

<script src="https://uparfait.github.io/accessibility/v1/widgets/accessibles.js?color=%237B3F00&position=bottom-left" defer></script>

In an address, # is written as %23. If you forget and write color=#7B3F00, it still works.

In a config object

<script>
  window.AccessiblesConfig = { color: '#7B3F00', position: 'bottom-left' };
</script>

This one has to come before the widget's script. If an option is set in two places, the data attribute wins, then the script address.

All options

OptionDefaultWhat it does
color#2F6B5AMain color of the button, highlights and active switches. Any CSS color works: #7B3F00, rgb(123,63,0) or chocolate.
icon-colorautomaticColor of the icon on the button. By default it is white or near-black, whichever is easier to see on your color.
bg#000000Background of the panel. Text and borders adjust to stay readable, so a light color gives a light panel.
site-namenoneYour site's name. It becomes the panel title and is used in the statement and in reports.
site-icon-urlnoneYour site's icon, shown in the panel header and next to the button.
positionbottom-rightbottom-right, bottom-left, bottom-center, top-right, top-left, top-center, right-center or left-center. Short forms like left work too.
offset20Space between the button and the edge of the screen, in pixels. offsetx and offsety set each side.
titleAccessibilityPanel title. With site-name set, it becomes the line under the name.
statementnoneAddress of your accessibility statement. Without it, a short built-in statement is shown.
reportnoneWhere issue reports go: an email address, or an address on your server that receives the report as JSON.
analyticsnoneAn address that receives a small, anonymous note each time a feature is used.
sizenonelarge starts with the bigger version of the panel.
draggabletrueSet to false so visitors can't move the button.
langnoneLanguage of the page, used when the page itself doesn't say.
readable-font-urlGoogle FontsLoad the easy-to-read font from your own server.
dyslexic-font-urlGoogle FontsLoad the dyslexia font from your own server.
dictionarydictionaryapi.devYour own dictionary address, with {word} and {lang} in it.

Examples

Your statement and your reports

<div class="accessibles-widget"
     data-statement="/accessibility"
     data-report="help@example.org"></div>

With an email address, the report opens the visitor's email app with the message filled in. With an address on your server, the report arrives as JSON like this:

{
  "site": "Green Valley Library",
  "type": "A form does not work for me",
  "message": "The search button does nothing with the keyboard.",
  "email": "reader@example.org",
  "page": "https://example.org/catalog",
  "settings": { "fontSize": 1.3, "focusRing": true },
  "time": "2026-11-17T09:30:00.000Z"
}

A light panel with your name and icon

<div class="accessibles-widget"
     data-site-name="Green Valley Library"
     data-site-icon-url="/img/logo.svg"
     data-bg="#FBFAF6"></div>
