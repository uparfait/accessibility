Profiles

A profile turns on a group of settings made for one need, all in one click.

Good to know

  • You can turn on more than one profile
  • You can still change each setting in the other tabs
  • Turning a profile off undoes exactly what it changed

Shortcut

  • Alt + A: open or close this menu

The profiles

Seizure safeMakes the page calmer and safer if flashing or movement can trigger seizures.Vision impairedMakes the page easier to see.ADHD friendlyHelps you focus on one part of the page at a time.Cognitive disabilityMakes the page simpler to follow and understand.DyslexiaMakes text easier to read with dyslexia.Color blindAdjusts colors so they are easier to tell apart if you are color blind.Motor impairedMakes the page easier to use if a mouse is hard for you.Blind usersPrepares the page for screen readers such as NVDA, JAWS, VoiceOver and TalkBack.Older adultsMakes the page more comfortable to read and use.
