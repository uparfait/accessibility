Accessibility tools for any website

Accessibles adds a small button to your site. Visitors use it to make text bigger, change colors, stop animations, hear the page read aloud or move around by voice. It also adds missing labels and image descriptions to the page, without any changes to your HTML.

Add it to your site
  • ProfilesNine one-switch setups, for vision, dyslexia, ADHD, seizures and more.
  • TextSize, fonts, spacing, alignment and right-to-left layout.
  • ColorDark, light and smart contrast, color blindness correction, custom colors.
  • NavigateKeyboard shortcuts, big cursors, on-screen keyboard and voice commands.
  • ReadingRead aloud, reading mask, reader view, dictionary, summary and translation.
  • RepairsMissing ARIA, alt text and form labels fixed automatically, and a page check.

How to use

There's nothing to install or build. Add the script and the button appears.

  1. Add two lines to your page

    Paste them just before the closing </body> tag.

    <div class="accessibles-widget"></div>
<script src="https://uparfait.github.io/accessibility/accessibles.js" defer></script>

  2. Make it yours

    Set options in the script URL or as data- attributes on the div. Write # as %23 in URLs.

    OptionWhat it does
    colorMain color of the button and highlights. Any CSS color.
    bgPanel background. Text and borders adjust to stay readable.
    positionWhere the button sits, such as bottom-left or right-center.
    site-nameYour site's name, shown as the panel title.
    site-icon-urlYour site's icon, shown in the panel header.
    statementLink to your accessibility statement.
    reportEmail address or URL that receives issue reports.

    Every option, setting and hook is listed in the README.

  3. Open it

    Visitors click the button or press Alt + A. Their choices are saved for the next visit.

Turn features on from your code

Your own buttons can switch profiles and settings.

Accessibles.profile('dyslexia');
Accessibles.set('fontSize', 1.3);

Listen for changes

React when a visitor changes a setting in the panel.

addEventListener('accessibles:change', e => {
  console.log(e.detail.key, e.detail.value);
});
