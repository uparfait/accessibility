Install

Accessibles is a script you add to your pages. There is nothing to build, and nothing to install on your server.

1. Add two lines

Open the HTML of your page, or the template that every page uses, and paste these lines just before the closing </body> tag:

<div class="accessibles-widget"></div>
<script src="https://uparfait.github.io/accessibility/v1/widgets/accessibles.js" defer></script>

The first line is the place where the widget lives. The second line loads it.

2. Check that it works

  1. Save the page and open it in your browser.
  2. A round button appears in the bottom-right corner.
  3. Click it, or press Alt + A, and the panel opens.
  4. Turn on Bigger text. The text of your page grows.

You can try the same thing right here. The preview below is a tiny web page with the two lines in it.

Good to know

  • The div is optional. If the script can't find one, it adds it.
  • defer is optional too. The script waits for the page either way, so it also works when a tag manager adds it.
  • On WordPress, Wix, Shopify and similar tools, paste the two lines where the site lets you add code to the footer.
  • In React, Vue or Angular apps, put them in the main index.html. The widget keeps working as the app changes pages.
  • Visitors' choices are saved in their browser, so they keep their settings on every page and on their next visit.

Host it yourself

You can also keep the files on your own server:

  1. Download the project from GitHub.
  2. Copy the whole v1/widgets folder to your site. Keep the files inside it together.
  3. Change the address in the script tag to your copy, such as /v1/widgets/accessibles.js.

Next, make the widget match your site on the Options page.
