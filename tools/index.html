Tools

Repairs that run quietly in the background, and options for the panel itself.

In this tab

  • Automatic repairs for screen readers, pictures and forms
  • Menu size, button position and saving your settings
  • Page check, problem report and accessibility statement
  • Reset all settings

The features

ARIA fixesAdds information that screen readers need. You will not see any change.Image descriptionsAdds short descriptions to pictures that have none, so screen reader users know what they show.Form fixesMakes forms easier to use with a screen reader.Larger featuresMakes this menu bigger, with larger text and buttons.Feature positionMoves the accessibility button.Remember settingsKeeps your settings for your next visit and for other pages.Page checkChecks this page for common accessibility problems and gives it a score.Report an issueTells the website owner about a problem, so they can fix it.Accessibility statementExplains how this website supports accessibility and how to get help.Reset allTurns every setting off and puts the page and this menu back the way they were at the start.
