Guide/Text

Content scaling

Makes the whole page bigger: text, pictures and buttons together.

How to use

  1. Press once to make the page bigger
  2. Press again for the next size
  3. Keep pressing to go back to the normal size

Sizes

  • 110%, 125%, 140% and 160%

Use it from your own code

The setting is called contentScale. It takes these values: 1, 1.1, 1.25, 1.4, 1.6. The first one, 1, means normal.

Accessibles.set('contentScale', 1.25);
Accessibles.set('contentScale', 1);   // back to normal
